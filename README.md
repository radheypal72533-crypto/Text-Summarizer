# 🧠 Text Summarizer

This is a simple Text Summarizer built using Python and HuggingFace Transformers.
It takes long text as input and generates a short, meaningful summary.

---

## 🚀 Features

* Summarizes long text quickly
* Easy to use interface
* Powered by NLP models

---

## 🛠️ Tech Stack

* Python
* FastAPI
* HuggingFace Transformers
* HTML, CSS

---

## ▶️ How to Run

```
pip install -r requirements.txt
uvicorn app:app --reload
```

---

## 💡 Usage

Enter your text and get a concise summary instantly.
